# Minimal Power Button Image

## Goal

Create a reusable PNG button graphic similar to the supplied reference.

## Design

- Transparent background
- Centered black power symbol
- Thin, clean, rounded linework
- No text, shadow, watermark, or extra decoration
- 512x512 output with antialiased edges

## Acceptance Criteria

The exported PNG has a genuine alpha channel, a balanced centered symbol, and remains legible when displayed at small UI sizes.
